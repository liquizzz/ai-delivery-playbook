# C4 diagrams: <Project name>

Save as `docs/tech/c4.md`. Levels 1 and 2 of the [C4 model](https://c4model.com). GitHub renders the Mermaid blocks below. Replace every label in *Title Case* with your own names; keep the shapes: rounded boxes are people, cylinders are data stores.

## Level 1: System context
Who uses the system and which other systems it talks to.

```mermaid
flowchart TB
  user(["Primary User"])
  admin(["Admin or Editor"])
  sys["Product System<br/>what it does in one line"]
  ext1[("Source System<br/>e.g. existing database")]
  ext2["External Service<br/>e.g. email, payments"]
  user -->|"uses, via web or app"| sys
  admin -->|"manages content"| sys
  sys -->|"reads, read-only"| ext1
  sys -->|"calls API"| ext2
```

## Level 2: Containers
The deployable parts and how they communicate.

```mermaid
flowchart TB
  user(["Primary User"])
  subgraph sys["Product System"]
    ui["Front End<br/>technology"]
    api["API<br/>technology"]
    worker["Worker or Job<br/>technology"]
    db[("Database<br/>technology")]
  end
  src[("Source System")]
  user -->|HTTPS| ui
  ui -->|"JSON over HTTPS"| api
  api -->|SQL| db
  worker -->|"reads, read-only"| src
  worker -->|writes| db
```
